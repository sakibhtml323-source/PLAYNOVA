# PLAYNOVA v3 — free HTML5 game portal (static, GitHub Pages)
500 browser games, browser-local profile (XP, coins, achievements, shop), per-game Progress drawer (stats, challenges, save download/import/reset, related games), sandboxed games with a validated storage/event bridge, offline cache for visited pages.
* Start here: reports/COMPLETE-AUDIT-REPORT.md · Deploy: reports/DEPLOYMENT-GUIDE.md
* Reports: reports/ (BUG-FIX, SECURITY, SEO, PERFORMANCE, MOBILE, OFFLINE, TEST-RESULTS.json) · per-game QA: reports/GAMEPLAY-QA-REPORT.csv · GAME_INTEGRATION_AUDIT.csv
* Limits: KNOWN_LIMITATIONS.md · Contract for games: INTEGRATION_CONTRACT.md, ADD-NEW-GAME-BN.md
* Older reports are in previous_release_reports/ and may be outdated.
Run tests: `pip install playwright && playwright install chromium && python3 tests/run_all.py`
